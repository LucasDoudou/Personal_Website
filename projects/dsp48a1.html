Front-End & Back-End Implementation of DSP48A1

A transistor-/layout-level digital IC implementation project covering schematic design, simulation, manual layout, and post-layout verification.

LinkedIn project / GitHub link ↗

Scope

Led implementation of the core functionality of a DSP48A1 digital signal-processing unit in Cadence Virtuoso.

Design flow

  • Schematic design
  • Pre-layout simulation
  • Manual layout design
  • Post-layout simulation

Implemented modules

  • 5-bit full adder
  • 11-bit full adder
  • 5 × 6 multiplier
  • 12-bit RAM block for serial-to-parallel data conversion in SPI read mode

What this project demonstrates

Hands-on digital IC implementation across front-end and back-end stages, with responsibility for coordinating the project as team lead.

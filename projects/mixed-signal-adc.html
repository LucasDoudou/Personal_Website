Mixed-Signal Temperature Sensor ADC

A low-power IoT analog front end implemented in Cadence Virtuoso using the SkyWater 130 nm process design kit.

LinkedIn project / GitHub link ↗

Scope

Worked as a core member integrating an analog front end for a low-power IoT system-on-chip across a 1.8–3.2 V battery-voltage range and a 0–70°C temperature range.

Integrated blocks

  • Low-dropout regulator (LDO)
  • Bandgap reference
  • Temperature sensor with a SAR ADC
  • Programmable-gain amplifier (PGA)

Circuit approach

The PGA used a folded-cascode operational amplifier. The project was implemented using the SkyWater 130 nm PDK in Cadence Virtuoso.

What this project demonstrates

Mixed-signal IC integration, analog building-block design, process-aware circuit implementation, and system-level thinking across supply and temperature variation.

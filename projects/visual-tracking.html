TI Cup Competition · May–Oct. 2023

Dynamic Color Block Tracking System

A real-time visual-control system combining computer vision, two microcontrollers, motor control, PID feedback, and multiple peripheral interfaces.

LinkedIn project / GitHub link ↗

System

Built a real-time tracking system using four steering motors, two OpenMV cameras programmed in MicroPython, and two STM32F4 microcontrollers.

Control

Implemented PID control to track moving red and green light spots on a whiteboard.

Integration

  • OLED display
  • ADC/DAC modules
  • UART communication between the two STM32F4 microcontrollers
  • Communication between OpenMV cameras and the microcontrollers

What this project demonstrates

Embedded-system integration across sensing, vision, control, actuation, real-time communication, and hardware debugging while leading a competition team.
